# Инструкция для AI-сессии (агент)

1. Прочитать `openspec/project.md` и `openspec/changes/*`.
2. Код меняется только в рамках папки изменения со спекой.
3. Спеки и комментарии — по-русски.
4. Секреты — только в `secrets/agent.env.enc`, пароль вне репозитория.
5. Не перезагружать серверы без разрешения владельца; помнить, что на этом же сервере живёт VPN-инфраструктура.
