# Спека домена ops

## ADDED Requirements

### Requirement: Журналирование — в ops
Модуль журналирования ДОЛЖЕН жить в `src/ops/`: ядро и домены получают его как зависимость
и не создают собственных логгеров с другим форматом.

#### Scenario: Лог сервиса
- GIVEN сервис пишет события
- WHEN событие логируется
- THEN формат и уровни те же, что раньше
- AND место модуля — `src/ops/logger.mjs`

### Requirement: Пустой интервал сторожа является успехом
Сторож завершённых задач ДОЛЖЕН завершаться с кодом 0 и продвигать маркер проверки,
если журнал доступен, но после прежнего маркера нет строк `dsh run finished`.

#### Scenario: За минуту задачи не завершались
- GIVEN маркер предыдущей проверки существует
- AND журнал не содержит новых завершений DSH
- WHEN запускается `agent-run-watch`
- THEN процесс завершается с кодом 0
- AND маркер получает новое время
- AND уведомление не отправляется.

### Requirement: Деплой обновляет установленный сторож
Штатный установщик ДОЛЖЕН обновлять бинарник `agent-run-watch`, если его systemd-unit
уже установлен, и НЕ ДОЛЖЕН сам включать отсутствующую интеграцию.

#### Scenario: Сторож настроен ранее
- GIVEN `agent-run-watch.service` существует
- WHEN устанавливается новый релиз агента
- THEN `/usr/local/bin/agent-run-watch` обновлён из релиза
- AND расписание существующего timer сохраняется.
