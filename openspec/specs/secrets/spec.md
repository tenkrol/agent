# Спека домена secrets

## ADDED Requirements

### Requirement: Крипто проверяется отдельно от файлов
Логика шифрования ДОЛЖНА быть чистыми функциями: ключ из пароля (scrypt), `seal`, `open`,
проверка конверта. Работа с файлами и разбор argv живут отдельно.

#### Scenario: Roundtrip
- GIVEN пароль и текст окружения
- WHEN текст шифруется и расшифровывается тем же паролем
- THEN получается исходный текст
- AND конверт содержит `v:1`, соль, iv и тег

#### Scenario: Неверный пароль
- GIVEN конверт, зашифрованный другим паролем
- WHEN выполняется `open`
- THEN возвращается ошибка «не расшифровывается» с кодом 3
- AND текст не выдаётся частично

### Requirement: Файл секретов трогает только домен secrets
Ни один другой модуль НЕ ДОЛЖЕН читать или писать `secrets/agent.env.enc` напрямую.

#### Scenario: Чужой модуль читает шифртекст
- GIVEN в `src/` вне `src/secrets/` появляется обращение к файлу секретов
- WHEN запускается сторожевой тест
- THEN тест падает и указывает файл

### Requirement: Пароль не попадает в argv и в логи
Пароль ДОЛЖЕН приходить только через окружение (`SECRETS_PASSPHRASE`); значения ключей
НЕ ДОЛЖНЫ печататься: `check` выводит только имена переменных.

#### Scenario: Проверка файла
- GIVEN зашифрованный файл и верный пароль
- WHEN выполняется `check`
- THEN вывод содержит число переменных и их имена
- AND ни одного значения

### Requirement: Реестр имён без значений
`secrets/keys.md` ДОЛЖЕН перечислять переменные, их назначение и источник, но не содержать
значений ключей.

#### Scenario: Реестр после добавления ключа
- GIVEN в реестр добавляют новую переменную
- WHEN запускается сторожевой тест
- THEN таблица содержит только имена и описание
- AND тест не находит в файле похожих на секрет строк

### Requirement: Реестр и обёртки совместимы
`tools/secrets.mjs` и `tools/secrets.sh` ДОЛЖНЫ сохранить команды `encrypt|decrypt|check`
и коды возврата (2 — нет пароля или команды, 3 — не расшифровывается).

#### Scenario: Старый вызов
- GIVEN деплой-скрипт вызывает `bash tools/secrets.sh decrypt`
- WHEN обёртка выполняется после переноса
- THEN поведение и код возврата те же
- AND файл создаётся с правами 600
