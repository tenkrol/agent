# PLA-35 / E8: файловый агент

Основание: план E8. DSH-исполнитель один на все задачи; файловые задачи требуют
своего набора инструкций и могут использовать отдельный профиль модели.

## Что меняется
- Файловый исполнитель `files` (capabilities: files/documents/office) с
  файловым системным префиксом и отдельным modelProfile.
- Оркестратор выбирает исполнителя по задаче (`selectExecutor`), по умолчанию dsh.
- Реестр отдаёт `files` наравне с dsh/quick.

## Не входит
Отдельный процесс/провайдер; E9–E11.
