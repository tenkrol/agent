# Дельта для домена execution

## ADDED Requirements

### Requirement: Результат привязан к попытке
Исполнитель ДОЛЖЕН возвращать результат с идентификатором попытки и `generation`;
оркестратор принимает его, только если попытка всё ещё владеет арендой.

#### Scenario: Поздний результат
- GIVEN попытка потеряла аренду
- WHEN её результат приходит позже
- THEN он не меняет состояние задачи
- AND фиксируется в журнале как устаревший.
