# Дельта для домена storage

## ADDED Requirements

### Requirement: Журнал доставки событий
Хранилище ДОЛЖНО вести постоянный журнал событий доставки: идентификатор события, тип,
маршрут, содержимое, состояние, число и время попыток, подтверждение обработки.

#### Scenario: Сохранение события
- GIVEN событие результата сформировано
- WHEN оно ставится в очередь доставки
- THEN запись сохраняется до первой попытки отправки
- AND после перезапуска незавершённая доставка видна и может быть продолжена

#### Scenario: Подтверждение
- GIVEN событие отправлено
- WHEN получатель подтвердил обработку
- THEN в журнале отмечается подтверждение и время
- AND повторная отправка не планируется

### Requirement: Маршрут и версия в записи задачи
Запись задачи ДОЛЖНА хранить маршрут ответа, номер версии результата, корневую задачу и
связь ревизии.

#### Scenario: Задача из ассистента
- GIVEN задача поступила по контракту с маршрутом
- WHEN запись сохраняется
- THEN маршрут и версия сохранены вместе с задачей
- AND после перезапуска они доступны без обращения к ассистенту

#### Scenario: Прежняя запись
- GIVEN запись создана до обновления
- WHEN журнал загружается
- THEN маршрут считается личным чатом агента
- AND версия равна 1, корневая задача равна самой задаче

### Requirement: История версий результата
Хранилище ДОЛЖНО сохранять связь между версиями одной задачи и не терять прежние записи
до истечения срока хранения.

#### Scenario: Новая версия
- GIVEN у задачи есть результат версии 1
- WHEN создаётся ревизия
- THEN обе записи сохраняются
- AND по корневой задаче можно найти все версии
