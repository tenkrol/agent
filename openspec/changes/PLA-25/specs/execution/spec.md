# Дельта для домена execution

## ADDED Requirements

### Requirement: Отдельная сессия попытки
При per-task workspace новая задача ДОЛЖНА начинать отдельную DSH-сессию, кроме
продолжения вопроса, которое сохраняет сессию.

#### Scenario: Параллельные задачи
- GIVEN две задачи одного чата с per-task workspace
- WHEN они стартуют
- THEN каждая получает fresh session
- AND продолжение вопроса использует сохранённую сессию.
