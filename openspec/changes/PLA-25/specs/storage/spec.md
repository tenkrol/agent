# Дельта для домена storage

## ADDED Requirements

### Requirement: Retention рабочих папок задач
Старые `tasks/<id>` ДОЛЖНЫ удаляться по retention, не затрагивая активные и
незавершённые задачи.

#### Scenario: Старая папка
- GIVEN папка задачи старше срока
- WHEN выполняется очистка
- THEN она удаляется
- AND папки активных задач остаются.
