# PLA-25 / E1: контракт исполнителя и изоляция задач

Основание: `222.md`, E1. E0 закрыт (PLA-24). PLA-20 уже дал per-task workspace и
workers=2; не повторять.

## Зачем
- Реестр исполнителей знает только id/capabilities; нет статуса, лимитов, профиля
  модели и доступных инструментов.
- Два параллельных DSH-запуска одного чата могут делить session; нужен отдельный
  session/controller на попытку.
- Папки tasks/<id> накапливаются без retention.
- Нет лимита задач на пользователя.

## Что меняется
- Реестр агентов: `describe()` с id/capabilities/limits/modelProfile/tools/status.
- DSH-исполнитель объявляет лимиты и профиль; оркестратор отдаёт это наружу.
- Per-task workspace => fresh DSH session, если это не продолжение вопроса.
- Retention-очистка `tasks/<id>` по возрасту, кроме активных.
- `TASK_PER_USER_CONCURRENCY` (0 = без ограничения) в enqueueJob.

## Не входит
Новые LLM-провайдеры/активность (E2), GitHub (E3), автодеплой (E7).
