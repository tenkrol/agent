# Дельта для домена verification

## ADDED Requirements

### Requirement: Критерии выводятся из запроса
Домен ДОЛЖЕН выводить проверяемые критерии результата из формулировки владельца и типа
результата. Критерий ДОЛЖЕН ссылаться на фразу запроса или на минимальную проверку типа;
придумывать новые требования запрещено.

#### Scenario: Формат и разделы
- GIVEN владелец указал формат и обязательные разделы
- WHEN строятся критерии
- THEN критерии покрывают формат и разделы
- AND не добавляют разделов, которых владелец не просил

#### Scenario: Источники
- GIVEN владелец требует источники
- WHEN строится критерий
- THEN наличие источников становится обязательным критерием
- AND проверка ссылается на этот критерий

### Requirement: Минимальные проверки по типу результата
Домен ДОЛЖЕН применять минимальные проверки, соответствующие результату:

| Результат | Минимальная проверка |
|---|---|
| Документ | Файл открывается, содержит требуемые разделы; при значимых требованиях к оформлению проверяется отображение |
| Таблица | Файл открывается, нужные данные присутствуют, применимые формулы пересчитаны и проверены |
| Изменение кода | Выполнены подходящие проверки; результат и ограничения зафиксированы |
| Исследование | Выводы связаны с источниками, предположения отделены от подтверждённых сведений |

#### Scenario: Документ без раздела
- GIVEN документ открывается, но обязательного раздела нет
- WHEN проверка завершается
- THEN критерий раздела получает статус «провален»
- AND итог не «проверено успешно»

#### Scenario: Ошибка формулы
- GIVEN таблица содержит формулу с ошибкой
- WHEN формулы пересчитаны
- THEN проверка фиксирует ошибку
- AND результат не считается верным

### Requirement: Статусы проверки
Проверка ДОЛЖНА возвращать статус «пройдена», «провалена», «частично», «недоступна» или
«не требуется» и список результатов по каждому критерию с доказательством.

#### Scenario: Недоступная проверка
- GIVEN окружение не позволяет выполнить проверку
- WHEN домен возвращает результат
- THEN статус «недоступна» и причина в ограничениях
- AND это не считается успешной проверкой

### Requirement: Проверка не выдаёт результат за проверенный
Домен НЕ ДОЛЖЕН возвращать успешный статус, если обязательный критерий не проверен или
провален.

#### Scenario: Нет доказательства
- GIVEN по критерию нет доказательства
- WHEN итог вычисляется
- THEN статус не «пройдена»
- AND причина попадает в ограничения
