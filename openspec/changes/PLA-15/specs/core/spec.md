# Дельта для домена core

## ADDED Requirements

### Requirement: Критерии результата до выполнения
Для сложного поручения ядро ДОЛЖНО получить проверяемые критерии результата из запроса
владельца до запуска исполнителя. Существенная неоднозначность ДОЛЖНА приводить к
уточнению, а не к догадке. Критерии не должны расширять объём поручения.

#### Scenario: Создание отчёта
- GIVEN владелец запросил отчёт с указанными разделами и источниками
- WHEN задача подготовлена к выполнению
- THEN критерии включают требуемый формат, разделы и наличие источников
- AND результат проверяется по этим критериям

#### Scenario: Неоднозначность
- GIVEN из запроса нельзя понять обязательный формат результата
- WHEN агент готовит критерии
- THEN он задаёт один уточняющий вопрос
- AND не запускает исполнителя до ответа

### Requirement: Проверка перед завершением
Успешное завершение исполнителя само по себе НЕ ДОЛЖНО означать успешное выполнение
поручения. Ядро ДОЛЖНО применить проверки, соответствующие результату, и только затем
выставить финальное состояние.

#### Scenario: Проверка пройдена
- GIVEN исполнитель создал файл и обязательные проверки прошли
- WHEN задача завершается
- THEN состояние «завершена»
- AND в отчёте перечислено, что проверено

#### Scenario: Проверка не пройдена
- GIVEN исполнитель создал файл
- WHEN обязательная проверка обнаруживает ошибку
- THEN агент пытается исправить результат в пределах бюджета
- AND при невозможности исправления сообщает о частичном результате или ошибке

#### Scenario: Проверка недоступна
- GIVEN необходимая проверка не может быть выполнена
- WHEN агент выдаёт результат
- THEN он явно сообщает, что именно не проверено
- AND не представляет результат как полностью проверенный

### Requirement: Состояния проверки
Задача ДОЛЖНА проходить состояние «проверяется» и завершаться либо как «завершена», либо
как «завершена частично», если обязательные проверки не выполнены.

#### Scenario: Частичный результат
- GIVEN обязательная проверка не прошла после всех попыток
- WHEN задача закрывается
- THEN состояние «завершена частично»
- AND заголовок отчёта не выдаёт результат за полный успех

### Requirement: Исправление в пределах бюджета
Повторное исправление ДОЛЖНО быть ограничено настройкой числа попыток и общими лимитами
времени, шагов и токенов задачи.

#### Scenario: Бюджет исчерпан
- GIVEN все попытки исправления израсходованы
- WHEN проверка снова не проходит
- THEN задача закрывается частичным результатом
- AND отчёт перечисляет проваленные критерии
