# Дельта для домена tools

## ADDED Requirements

### Requirement: Инспекция документа
Домен ДОЛЖЕН предоставлять проверку документа: открывается ли файл, какой текст содержит,
какие разделы присутствуют. Для значимых требований к оформлению — рендер отображения
(страницы, изображение) для последующей проверки.

#### Scenario: Валидный документ
- GIVEN документ создан
- WHEN домен его инспектирует
- THEN файл открывается, текст и разделы доступны
- AND при требовании к оформлению доступен рендер

#### Scenario: Битый документ
- GIVEN файл повреждён
- WHEN домен его инспектирует
- THEN возвращается ошибка открытия
- AND проверка не считается пройденной

### Requirement: Инспекция и пересчёт таблицы
Домен ДОЛЖЕН предоставлять открытие таблицы, чтение листов и значений, список формул,
ошибки формул и пересчёт формул локальным офисным движком.

#### Scenario: Пересчёт формул
- GIVEN таблица содержит формулы
- WHEN домен пересчитывает её
- THEN возвращаются вычисленные значения
- AND ошибки формул перечислены отдельно

### Requirement: Проверки не расширяют прав
Инспекция и рендер ДОЛЖНЫ работать только с файлами рабочей папки задачи и в тех же
ограничениях, что и остальные инструменты домена.

#### Scenario: Чужой путь
- GIVEN проверка просит файл вне рабочей папки
- WHEN домен обрабатывает запрос
- THEN запрос отклоняется
- AND файл не читается
