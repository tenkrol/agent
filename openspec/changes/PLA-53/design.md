# Техническое решение

`agent-run-watch` получает переопределяемый `STATE_ROOT`, чтобы регрессионный тест
работал в временном каталоге без root. Чтение журнала выполняется через process
substitution, где отсутствие совпадений явно нормализуется в успешный результат.
Основной цикл остаётся тем же, а маркер записывается после каждой успешной проверки.

`install-remote.sh` копирует сторож в `/usr/local/bin`, только если его systemd-unit
уже установлен. Поэтому обычный деплой обновляет существующую интеграцию и не включает
её на серверах, где `setup-outbox.sh` раньше не запускался.
