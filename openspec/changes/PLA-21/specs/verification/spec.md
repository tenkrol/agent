# Дельта для домена verification

## ADDED Requirements

### Requirement: Проверка прерывается отменой
Проверка ДОЛЖНА принимать сигнал отмены и передавать его всем портам: модели,
LibreOffice, запуску тестов. При уже отменённом сигнале порты не вызываются; поздний
ответ не меняет терминальный исход.

#### Scenario: Отмена до модели
- GIVEN сигнал уже отменён
- WHEN вызывается проверка исследования
- THEN модельный порт не вызывается
- AND проверка не выдаёт `passed`.

#### Scenario: Отмена во время пересчёта
- GIVEN идёт LibreOffice
- WHEN сигнал отменяется
- THEN процесс убивается
- AND проверка завершается без ложного успеха.

### Requirement: Расход проверки учитывается
Проверяющая модель ДОЛЖНА возвращать usage вместе с текстом; расход проверки входит в
общий бюджет задачи.

#### Scenario: Учёт модели
- GIVEN модель вернула usage
- WHEN проверка завершилась
- THEN оркестратор вычитает этот расход из остатка.
