# Техническое решение

## Как устроено сейчас
`safeSend` после успешной отправки в чат агента вызывает `mirrorToAssistant(markdown, …)`.
Через `safeSend` идут все сообщения: статусы, прогресс (правки), ответы команд, сводки,
алерты. Поэтому в бота попадает всё.

## Предлагаемое решение
- Убрать вызов из `safeSend`.
- Добавить метод `mirrorResult(text)`: один вызов `this.mirror` с логированием неудачи, не
  влияющий на отправку в чат агента.
- Зеркалировать явно в четырёх местах:
  `reportResult` (финальный ответ), быстрый ответ (`quick.text`), `parkForAnswer`
  (вопрос), `parkForVariants` (текст с вариантами).
- Конструктор принимает `mirror` (по умолчанию `mirrorToAssistant`) — в тестах подставляется
  заглушка вместо сети.
- План на утверждение не зеркалируется: кнопки работают только в чате агента, в боте они
  бесполезны.

## Влияние
- Ответ в чате агента не меняется; меняется только состав зеркалирования.
- Риск: забыть зеркалирование нового вида результата — закрывается тестами на оба вида.
- Откат: симлинк на предыдущий релиз.

## Альтернативы
- Флаг `mirror: true` в `safeSend` у нужных вызовов — работает, но легко снова получить поток,
  если флаг поставят по ошибке; явный метод читается лучше.
- Фильтрация по началу текста («✅», «⏳») — хрупко: тексты меняются.
