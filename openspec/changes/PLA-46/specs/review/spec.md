# Дельта для домена review

## ADDED Requirements

### Requirement: Предложение review
Предложение ДОЛЖНО содержать источник/доказательство, почему сейчас, ожидаемую пользу,
стоимость и способ проверки; 1–3 предложения за вызов.

#### Scenario: Источник недоступен
- GIVEN наблюдатель вернул unavailable
- WHEN вызывается review
- THEN предложение содержит проверку доступа и источник.
