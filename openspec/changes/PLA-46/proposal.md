# PLA-46 (3.3): ручной /review

Основание: раздел 3.3. Нужны 1–3 предложения с источником, «почему сейчас», пользой,
стоимостью и способом проверки; без дублирования существующего обзора бота.

## Что меняется
- `workflow/review` строит предложения из результатов наблюдателей: недоступный
  источник, изменения в репозиториях, состояние сервера.
- Контракт suggestion: id, title, sources, whyNow, benefit, cost, verify.
- API `/v1/review`; теневая/инициативная доставка — следующими изменениями.
