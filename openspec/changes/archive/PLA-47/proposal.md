# PLA-47 (3.4): теневой режим предложений

Основание: раздел 3.4. Нужно собирать предложения и оценивать качество без отправки
и автоматических действий.

## Что меняется
- `workflow/shadow`: сохраняет предложения review, решения владельца/наблюдателя,
  результат и метрики; ничего не отправляет.
- API `/v1/shadow` (collect/decide/stats).
- Инициативная доставка подключается только следующим изменением.
