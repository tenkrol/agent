# Дельта для домена config

## MODIFIED Requirements

### Requirement: Набор переменных и умолчаний не меняется
Перенос ДОЛЖЕН сохранять все существующие переменные, их значения по умолчанию, границы
и форматы (время `ЧЧ:ММ`, список пользователей, абсолютные пути). Набор переменных МОЖЕТ
дополняться новыми ключами контракта v2 и доставки, если выполнены три условия: у каждого
нового ключа есть значение по умолчанию, при котором поведение без ключа остаётся прежним;
старый `/etc/agent/agent.env` поднимается без новых ключей; неверное значение нового ключа
даёт понятную ошибку при старте.

#### Scenario: Старое окружение
- GIVEN старый `/etc/agent/agent.env` без новых ключей
- WHEN сервис стартует после обновления
- THEN конфиг собирается без ошибок
- AND поведение агента не меняется: прежний `/bridge` и `/outbox` работают

#### Scenario: Новый ключ
- GIVEN в окружение добавлен ключ контракта v2
- WHEN конфиг собирается
- THEN ключ провалидирован и имеет документированное значение по умолчанию
- AND остальные переменные не изменились

#### Scenario: Неверное значение
- GIVEN `DELIVERY_MAX_ATTEMPTS=0`
- WHEN сервис запускается
- THEN старт прерывается ошибкой с именем переменной и допустимыми границами
- AND сообщение не раскрывает значения секретов

## ADDED Requirements

### Requirement: Настройки контракта v2 и доставки
Домен `config` ДОЛЖЕН содержать настройки контракта v2, файлов и доставки, отдавать их
остальным доменам готовыми значениями и не требовать чтения `process.env` вне `config`.

| Ключ | Значение по умолчанию | Валидация |
|---|---|---|
| `CONTRACT_V2` | `true` | true/false |
| `BRIDGE_ROUTE_BOT_ID` | пусто | строка; пусто — маршрут не ограничен по боту |
| `BRIDGE_ROUTE_CHAT_ID` | пусто | строка; пусто — маршрут не ограничен по чату |
| `DELIVERY_TICK_MS` | `30000` | целое 1000…600000 |
| `DELIVERY_RETRY_MS` | `60000,300000,900000,3600000,21600000` | список целых ≥ 1000 |
| `DELIVERY_MAX_ATTEMPTS` | `8` | целое 1…50 |
| `DELIVERY_TEXT_CHARS` | `3500` | целое 500…4096 |
| `FILES_MAX_BYTES` | `20971520` | целое 1024…104857600 |

#### Scenario: Значения по умолчанию
- GIVEN новые ключи не заданы
- WHEN сервис стартует
- THEN `CONTRACT_V2=true`, доставка работает с тиком 30 с и восемью попытками
- AND текст ассистенту обрезается до 3 500 символов

#### Scenario: Отключение контракта v2
- GIVEN `CONTRACT_V2=false`
- WHEN сервис стартует
- THEN `/v1/*` не включается, работают прежние `/bridge` и `/outbox`
- AND остальные настройки не меняются

#### Scenario: Ограничение маршрута
- GIVEN заданы `BRIDGE_ROUTE_BOT_ID` и `BRIDGE_ROUTE_CHAT_ID`
- WHEN приходит задача с чужим маршрутом
- THEN домен `bot-link` отклоняет запрос
- AND значения маршрута берутся из `config`, а не из окружения напрямую

#### Scenario: Неверный список повторов
- GIVEN `DELIVERY_RETRY_MS` содержит нечисло
- WHEN конфиг собирается
- THEN старт прерывается ошибкой `DELIVERY_RETRY_MS: …`
- AND понятно, что нужен список целых миллисекунд

#### Scenario: Секреты не раскрываются
- GIVEN в настройках есть токены
- WHEN конфиг печатается при диагностике
- THEN значения токенов маскируются
- AND новые ключи не добавляют секретов в открытом виде
