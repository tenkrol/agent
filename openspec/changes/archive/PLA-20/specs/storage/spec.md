# Дельта для домена storage

## ADDED Requirements

### Requirement: Транзакционная очередь с арендой
Очередь ДОЛЖНА хранить задачи транзакционно, выдавать аренду с `generation` и
отвергать результат устаревшей попытки.

#### Scenario: Два работника
- GIVEN в очереди одна задача
- WHEN два работника одновременно пытаются её захватить
- THEN задачу получает ровно один
- AND второй получает «нет работы».

#### Scenario: Устаревшая попытка
- GIVEN задача была перезахвачена с новым `generation`
- WHEN старая попытка пытается её завершить
- THEN запись отвергается
- AND задача не получает ложный терминальный статус.

#### Scenario: Потеря работника
- GIVEN аренда истекла, heartbeat не приходит
- WHEN другой работник захватывает задачу
- THEN создаётся новая попытка
- AND прежняя помечается потерянной.
