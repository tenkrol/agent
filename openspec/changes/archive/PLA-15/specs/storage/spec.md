# Дельта для домена storage

## ADDED Requirements

### Requirement: Критерии и результат проверки в записи задачи
Запись задачи ДОЛЖНА хранить критерии результата и результат проверки: статус, результаты
по критериям, доказательства, ограничения и число попыток.

#### Scenario: Задача проверена
- GIVEN проверка завершена
- WHEN запись задачи сохраняется
- THEN критерии и результат проверки доступны после перезапуска
- AND `/task <id>` может показать, что проверено

### Requirement: Совместимость старых записей
Записи без критериев и результата проверки ДОЛЖНЫ читаться как задачи, выполненные до
появления проверки, без ошибок загрузки.

#### Scenario: Старая задача
- GIVEN запись создана до обновления
- WHEN журнал загружается
- THEN запись читается
- AND новые поля считаются отсутствующими
