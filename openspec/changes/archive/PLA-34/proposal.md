# PLA-34 / E7: установка проверенной реализации

Основание: план E7. E6 гарантирует зелёные проверки на `impl/<REQ>-<changeId>`.

## Что меняется
- `workflow/deploy`: требование явного подтверждения (`confirm == requestId`),
  повторная проверка ветки, merge impl→main и установка через порт `install`.
- Без настроенного `install` деплой не выполняется: сначала подготовка, затем
  подключение конкретного установщика компонента.
- `POST /v1/deploy` с bearer-токеном и подтверждением.

## Не входит
Автоматический SSH к Испании; секреты и перезагрузки серверов.
