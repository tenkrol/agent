# PLA-48 (3.5): инициативы с лимитом, дедупом и тихими часами

Основание: раздел 3.5. Предложения не должны дублироваться, приходить ночью или
превышать согласованный дневной лимит; решения «сделать/позже/не предлагать» должны
сохраняться.

## Что меняется
- `workflow/initiatives`: дневной лимит, дедупликация сигнатуры, тихие часы по поясу,
  решения do/later/never, журнал.
- API `/v1/initiatives` (propose/decide/list).
- Доставка остаётся за существующими механизмами бота.
