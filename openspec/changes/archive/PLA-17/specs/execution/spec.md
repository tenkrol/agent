# Дельта для домена execution

## ADDED Requirements

### Requirement: В задачу передаются только необходимые сведения
Промпт ДОЛЖЕН получать отобранные для задачи факты памяти в пределах бюджета
`MEMORY_CONTEXT_CHARS`, а не всю память целиком. Контекст других задач и не относящиеся к
делу личные сведения попадать НЕ ДОЛЖНЫ.

#### Scenario: Обычная задача
- GIVEN в памяти много фактов
- WHEN собирается промпт
- THEN в него попадают только действующие и относящиеся к задаче факты
- AND предел `MEMORY_CONTEXT_CHARS` соблюдается

#### Scenario: Задача без темы
- GIVEN задача не связана с сохранёнными рабочими фактами
- WHEN собирается промпт
- THEN попадают только общие предпочтения
- AND лишние факты не увеличивают промпт

### Requirement: Факты задачи не сохраняются
Факты, пришедшие с задачей от ассистента (`context.facts`), ДОЛЖНЫ использоваться только в
промпте этой задачи и НЕ ДОЛЖНЫ попадать в долговременную память агента или в другие
задачи.

#### Scenario: Задача с фактами ассистента
- GIVEN задача содержит `context.facts`
- WHEN собирается промпт и выполняется задача
- THEN факты попали в промпт этой задачи
- AND после завершения в памяти агента их нет

### Requirement: Секреты не попадают в промпт
Промпт НЕ ДОЛЖЕН содержать значения секретов. При обнаружении значения в собранном тексте
факт или фрагмент исключается, а в журнал пишется предупреждение без значения. Проверка
идёт через связанный guard-порт домена `secrets`; порт создаётся в точке сборки из
`config`, значения секретов в домен `execution` не передаются.

#### Scenario: Утечка в память
- GIVEN в памяти оказался фрагмент с секретом
- WHEN собирается промпт
- THEN фрагмент не включается
- AND записывается предупреждение с именем ключа
- AND сам промпт не содержит значения
