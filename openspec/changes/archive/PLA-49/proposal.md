# PLA-49 (3.6): политика действий автономного помощника

Основание: раздел 3.6. Действия должны иметь режимы observe/prepare/execute/approval,
общий выключатель, бюджет и отмену; произвольная команда от LLM не является действием.

## Что меняется
- `workflow/action-policy`: режимы, allowlist действий, approval, бюджет, глобальный
  выключатель и отмена.
- API `/v1/policy` для чтения/решения; доставка действий остаётся у существующих
  механизмов компонентов.
