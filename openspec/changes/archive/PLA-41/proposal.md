# PLA-41 / F4: честные профили специализированных агентов

Основание: review F4. files/monitor/personal объявляют modelProfile, но DSH-headless
получает один общий runner/model; профиль не переключает вызов.

## Что меняется
- Исполнитель явно объявляет `profileStatus: unsupported`, если DSH не умеет
  переключать модель; реестр показывает это, а не «действующий профиль».
- Usage/активность пишет фактический provider/model и роль исполнителя.
- Параллельные вызовы не меняют общий env: профиль не мутирует глобальную настройку.
- Конфиг профилей остаётся декларацией для будущего переключения.
