# PLA-26 / E2: активность агентов и API наблюдения

Основание: `222.md`, E2. E0/E1 закрыты. Не повторять существующие usage/реестр.

## Зачем
Расходы и события задач есть в журнале/usage, но нет единого API активности:
бот не может показать, кто что делает, какой агент/стадия, сколько потрачено.
Профили LLM пока общие.

## Что меняется
- `storage/activity`: журнал событий (queued/started/stage/completed/delivery/error)
  с taskId/agent/stage/tokens/status, без секретов; bounded retention.
- `GET /v1/agents` — реестр исполнителей (describe) + активные задачи.
- `GET /v1/activity?limit=&agent=&taskId=` — последние события.
- Бот пишет события при постановке/старте/завершении/доставке.
- `AGENT_PROFILE_*` заготовка профилей моделей (оркестратор/DSH/quick) без смены
  провайдера по умолчанию.

## Не входит
Смена провайдера, YandexGPT, UI бота (следующий шаг E2), GitHub.
