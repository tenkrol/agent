# Дельта для домена workflow

## ADDED Requirements

### Requirement: Крупное изменение — ветка и проверка
Изменение, меняющее жизненный цикл задач, ДОЛЖНО разрабатываться в отдельной ветке;
`main` обновляется после проверки. Прямой push в `main` для такого изменения не
допускается.

#### Scenario: Этап оркестратора
- GIVEN изменение затрагивает исполнение и отмену задач
- WHEN работа готова
- THEN код и спека лежат в ветке
- AND слияние выполняется после независимой проверки и прогона тестов.
