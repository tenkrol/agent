# Дельта для домена core

## MODIFIED Requirements

### Requirement: Ядро — только оркестрация
`core` ДОЛЖЕН принимать сообщение, готовить вход (вложения, план, вопрос), вызывать
оркестратор и доставлять ответ. Второго цикла исполнения, проверки или исправления в
`core` быть НЕ ДОЛЖНО.

#### Scenario: Исправление после проверки
- GIVEN проверка нашла проблемы
- WHEN запускается исправление
- THEN его ведёт оркестратор
- AND `core` не создаёт отдельный `AbortController` и не считает второй бюджет.
