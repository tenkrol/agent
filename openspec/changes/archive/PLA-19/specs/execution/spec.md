# Дельта для домена execution

## ADDED Requirements

### Requirement: Лимиты конкретного запуска
Раннер ДОЛЖЕН принимать лимиты конкретного запуска (токены, шаги, таймаут), не меняя
глобальные настройки; отсутствующее или нулевое значение означает «использовать
глобальное».

#### Scenario: Остаток исправления
- GIVEN оркестратор передал уменьшенный таймаут и бюджет
- WHEN DSH запускается
- THEN действует переданный лимит
- AND следующий обычный запуск снова использует глобальные настройки.
