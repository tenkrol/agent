# Дельта для домена workflow

## ADDED Requirements

### Requirement: Заявка и манифест
Доработка ДОЛЖНА иметь заявку с `manifest.json`: requestId, revision, компоненты,
changeId, base/specification SHA, зависимости и политики; манифест проверяется
валидатором до исполнения.

#### Scenario: Некорректный манифест
- GIVEN отсутствует specificationCommit
- WHEN манифест проверяется
- THEN проверка падает с понятной ошибкой
- AND задача не запускается.

### Requirement: Ветка → проверки → PR
Изменение кода ДОЛЖНО идти в ветке задачи, проходить проверки и PR; прямой push
доработки в main запрещён. Подтверждение относится к SHA спеки.

#### Scenario: Изменённая спека
- GIVEN спека принята на SHA A
- WHEN SHA меняется на B
- THEN прежнее подтверждение не действует автоматически
- AND нужна новая проверка/подтверждение.
