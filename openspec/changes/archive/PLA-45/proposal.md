# PLA-45 (3.2): наблюдатели GitHub и серверов

Основание: раздел 3.2. Нужен детерминированный реестр источников с свежестью и
доказательствами; недоступный источник не означает «изменений нет».

## Что меняется
- `workflow/observers`: реестр источников, observe() со статусом ok/unavailable,
  evidence, freshness и findings.
- GitHub-источник: последние коммиты через Git, без LLM.
- Серверный источник: порт probe (диск/память/сервис), без догадок.
- `/v1/observers` и `/v1/observe` для чтения состояния.
