# Решение

Источник = {id, kind, fetch()}. fetch возвращает evidence (например, SHA/метрики) или
бросает. Реестр никогда не подменяет unavailable пустым результатом: статус источника
явный, findings содержат source и evidence. GitHub-источник читает refs/коммиты через
Git-клиент; серверный — через probe-порт.
