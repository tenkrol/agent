# Дельта для домена acceptance

## ADDED Requirements

### Requirement: Приёмка с доказательствами
Приёмка плана ДОЛЖНА содержать по каждому этапу E0–E10 доказательство и статус;
недоказанные пункты помечаются partial/blocked.

#### Scenario: Нет доказательства
- GIVEN у этапа нет теста/live-задачи
- WHEN заполняется приёмка
- THEN статус не «passed».
