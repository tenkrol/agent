# PLA-29 / E4: из сообщения — в готовую спецификацию

Основание: `222.md`, E4. E3-инфраструктура готова: spec-репозиторий, manifest,
deploy keys, ветки компонентов.

## Что меняется (первый шаг)
- Домен `workflow`: генерация draft-заявки (request/proposal/acceptance/manifest)
  из текста владельца с явными компонентами, requestId и revision.
- Валидация manifest до записи; запрет секретов.
- Агентский API/бот-команда для создания заявки — следующий шаг.

## Не входит
LLM-анализ компонентов, автоподбор changeId, публикация PR, policy-режим.
