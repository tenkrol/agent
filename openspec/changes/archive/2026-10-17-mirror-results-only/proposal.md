# Изменение: в чат-бота уходит только результат и запрос дополнительной информации

## Зачем
Зеркалирование в чат-бота вызывается внутри `safeSend`, то есть **каждое** сообщение агента
уходит в бота: «приступаю», правки прогресса, отметки «выполнена», сводки, предупреждения о
лимите, алерты. Владелец получает поток служебных сообщений вместо результата.

## Что меняется
В чат-бота уходят только два вида сообщений:
1. **результат работы** — финальный ответ задачи (и быстрый ответ);
2. **запрос дополнительной информации** — уточняющий вопрос и предложенные варианты.

Служебные сообщения (статусы, прогресс, отметки, сводки, алерты, план на утверждение)
остаются только в чате агента.

## Чего не делаем
- Не меняем текст и формат зеркалируемых сообщений.
- Не трогаем протокол точки приёма (`postOutbox`), обрезку 3 500 символов и молчание при ошибке.
- Не меняем поведение самого чата агента: там все сообщения остаются как были.

## Как проверяем
- Тесты: при обычной задаче зеркалирование вызывается один раз и содержит ответ; при
  задаче с вопросом — один раз и содержит вопрос; служебные сообщения не зеркалируются.
- Живая проверка: задача через мост, в чат-боте только результат.
