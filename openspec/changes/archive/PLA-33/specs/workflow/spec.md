# Дельта для домена workflow

## ADDED Requirements

### Requirement: Проверки перед публикацией реализации
Ветка `impl/<REQ>-<changeId>` ДОЛЖНА публиковаться только после успешных проверок
компонента; при падении выполняется ограниченный repair, иначе ветка не пушится.

#### Scenario: Проверки упали
- GIVEN тесты реализации не проходят
- WHEN repair не исправил
- THEN ветка impl не публикуется
- AND ошибка возвращается вызывающему.
