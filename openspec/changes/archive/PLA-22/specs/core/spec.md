# Дельта для домена core

## MODIFIED Requirements

### Requirement: Ядро — только оркестрация
`core` ДОЛЖЕН преобразовывать вход и доставлять сообщения; очередь, восстановление,
awaiting и терминальные переходы принадлежат `orchestration`.

#### Scenario: Команды
- GIVEN владелец вызывает /tasks или /cancel
- WHEN команда обрабатывается
- THEN она читает состояние через orchestration
- AND не ведёт второй цикл исполнения.
