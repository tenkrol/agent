# Дельта для домена workflow

## MODIFIED Requirements

### Requirement: Проверки перед публикацией нельзя пропустить отменой
Workflow реализации ДОЛЖЕН считать отменённый прогон проверок отменой операции и НЕ
ДОЛЖЕН публиковать ветку или записывать состояние verified.

#### Scenario: Отмена между DSH и проверками
- GIVEN DSH завершил работу и настроены обязательные проверки
- WHEN signal отменён до или во время проверок
- THEN проверки завершаются AbortError
- AND ветка impl не публикуется
- AND состояние заявки становится cancelled.
