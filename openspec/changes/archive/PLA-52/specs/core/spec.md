# Дельта для домена core

## MODIFIED Requirements

### Requirement: Очередь соблюдает предел параллельности
Ядро ДОЛЖНО выполнять не больше `QUEUE_WORKERS` задач одновременно и ДОЛЖНО
запускать ожидающую задачу после освобождения слота.

#### Scenario: Четыре задачи и два worker
- GIVEN настроены два worker и четыре готовые задачи
- WHEN исполнители заблокированы до общего разрешения
- THEN одновременно запущено не больше двух исполнителей
- AND после их завершения выполняются оставшиеся задачи.

### Requirement: Отмена адресует конкретную попытку
Ядро ДОЛЖНО отменять активную задачу по её id, независимо от порядка параллельных
запусков, а при остановке сервиса — все активные попытки.

#### Scenario: Отменяется вторая задача
- GIVEN одновременно выполняются две задачи
- WHEN контракт отменяет вторую по id
- THEN signal второй задачи становится aborted
- AND первая задача не отменяется этим действием.

### Requirement: Очистка сохраняет workspace незавершённых задач
Ядро ДОЛЖНО загрузить журнал до очистки task-workspace и защитить каталоги всех
нетерминальных задач.

#### Scenario: Старый каталог ожидающей задачи
- GIVEN задача ожидает ответ владельца, а mtime её каталога старше retention
- WHEN сервис запускается
- THEN запись задачи восстанавливается
- AND файлы её workspace не удаляются.
