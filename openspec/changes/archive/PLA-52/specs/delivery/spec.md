# Дельта для домена delivery

## MODIFIED Requirements

### Requirement: Личная доставка подтверждается только после отправки
Личный текстовый результат ДОЛЖЕН записываться в долговечную очередь доставки до
отправки. Ошибка Telegram НЕ ДОЛЖНА переводить запись в acked и ДОЛЖНА оставлять её
для ограниченного повтора без повторного исполнения задачи.

#### Scenario: Telegram недоступен при итоговом ответе
- GIVEN задача завершена и личное событие сохранено
- WHEN sendText завершается ошибкой
- THEN запись доставки остаётся pending
- AND SQLite outbox снимается только после передачи события DeliveryWorker
- AND последующий tick повторяет тот же eventId.
