# Вопросы владельцу по PLA-51

Ниже — неопределённости, которые нельзя решать молча. Для каждого вопроса указана
рекомендация; если ответа нет, после одобрения спеки реализация идёт по рекомендации.

1. **Только контрольная строка или исполняемый E2E?**
   В заявке сказано «добавь в README строку Acceptance E2E smoke». Считать ли это
   только отметкой в документации (как `E5 implementation check`) или нужно добавить
   исполняемый E2E smoke-сценарий/команду?
   *Рекомендация:* только строка и тест-страж; исполняемый E2E — вне границ PLA-51.

2. **Точная формулировка и место.**
   Достаточно ли абзаца, первая строка которого начинается с `Acceptance E2E smoke`,
   в разделе «Тесты и разработка» сразу после блока E5? Допустимо ли пояснение после
   тире или нужна буквально строка без пояснений?
   *Рекомендация:* `Acceptance E2E smoke — ...` рядом с E5; тест проверяет начало
   строки, поэтому пояснение не мешает.

3. **Нужен ли автоматический тест?**
   Добавлять ли проверку в существующий `test/readme.test.mjs` или ограничиться
   правкой README?
   *Рекомендация:* добавить проверку по прецеденту E5 (PLA-32), чтобы строку не
   потеряли при будущих правках.

4. **Нужен ли деплой?**
   Изменение только документационное. Требуется ли `deploy/install-remote.sh` и
   проверка на сервере, или достаточно merge в `main` и зелёных тестов?
   *Рекомендация:* деплой не требуется; README попадёт в следующий штатный релиз.
