# PLA-51: контрольная строка `Acceptance E2E smoke` в README

## Зачем

Заявка REQ-0010 требует, чтобы README компонента содержал явную строку
`Acceptance E2E smoke` — контрольную отметку сквозной приёмки (E2E). Сейчас в README
есть только отметка E5 (`E5 implementation check`), поэтому результат REQ-0010 нельзя
подтвердить по документации: строку легко потерять при правках, а проверяющему
приходится искать её вручную.

## Что меняется

Наблюдаемое поведение после реализации:

- в README, в разделе «Тесты и разработка», сразу после абзаца с отметкой E5,
  появляется отдельный абзац, первая строка которого начинается с
  `Acceptance E2E smoke` (например,
  `Acceptance E2E smoke — контрольная строка README для заявки REQ-0010 (change PLA-51);`);
- `test/readme.test.mjs` дополняется проверкой: README содержит строку, начинающуюся
  с `Acceptance E2E smoke`; при удалении или переименовании строки проверка падает;
- существующая строка `E5 implementation check` и её тест сохраняются без изменений;
- проверки расхода в `test/plan.test.mjs` и `test/quick.test.mjs` используют тот же
  часовой пояс, что и бот, поэтому полный прогон не зависит от границы суток
  UTC/`Europe/Moscow`;
- поведение агента, HTTP-API, конфигурация, состояние и секреты не меняются.

## Чего не делаем

- Не добавляем исполняемый E2E-сценарий, новый раннер или отдельную CI-джобу: по
  формулировке заявки нужна контрольная строка в README и её тест-страж
  (см. `questions.md`, вопрос 1).
- Не переписываем разделы README сверх необходимого и не меняем существующую
  отметку E5.
- Не меняем `main` на этапе подготовки спеки: реализация — в отдельной ветке после
  одобрения (см. `design.md`).
- Не добавляем миграции данных, новые зависимости и изменения форматов.

## Как проверяем

- `node --test --test-force-exit test/readme.test.mjs` — оба теста (E5 и новый) зелёные.
- `bash tools/spec-check.sh` — структура изменения и дельта-спеки в порядке.
- `grep -n '^Acceptance E2E smoke' README.md` находит контрольную строку.
- Полный прогон `node --test --test-force-exit test/*.test.mjs` зелёный, включая
  проверки расхода в `plan.test.mjs` и `quick.test.mjs`.
- Успех: README содержит строку `Acceptance E2E smoke`, тест защищает её от потери,
  остальное поведение продукта не изменилось.
