# Дельта для домена core

## ADDED Requirements

### Requirement: Команды процедур
Ядро ДОЛЖНО предоставлять явные команды процедур: список, показ, сохранение из задачи,
явная правка, активация черновика, запуск и удаление. Сохранение и правка — только по
команде владельца.

#### Scenario: Сохранение с полными полями
- GIVEN владелец вызывает сохранение процедуры из выполненной задачи
- WHEN все обязательные поля выведены из задачи
- THEN создаётся активная версия, владелец видит имя и номер версии
- AND задача остаётся неизменной

#### Scenario: Сохранение с недостающими полями
- GIVEN из задачи нельзя вывести формат результата или критерии
- WHEN владелец вызывает сохранение
- THEN создаётся версия-черновик
- AND владелец видит, какие поля нужно заполнить, а `run` отклоняется

#### Scenario: Активация
- GIVEN черновик заполнен обязательными полями
- WHEN владелец активирует версию
- THEN версия становится действующей
- AND она доступна для запуска и расписания

#### Scenario: Запуск
- GIVEN у процедуры есть активная версия
- WHEN владелец запускает её
- THEN создаётся отдельная задача с зафиксированной версией
- AND в отчёте видно имя и версию процедуры

### Requirement: Процедура в расписании
Расписание ДОЛЖНО уметь запускать процедуру с параметрами, создавая отдельную задачу и
фиксируя фактическую версию. Расписание на черновик НЕ ДОЛЖНО создаваться.

#### Scenario: Запуск по расписанию
- GIVEN расписание указывает на активную процедуру
- WHEN наступает время
- THEN создаётся задача с активной версией процедуры и её критериями
- AND порядок и лимиты очереди соблюдаются

#### Scenario: Черновик в расписании
- GIVEN процедура не имеет активной версии
- WHEN владелец пытается поставить её в расписание
- THEN расписание не создаётся
- AND сообщение объясняет, что версия не активирована

#### Scenario: Закреплённая версия
- GIVEN в расписании явно указана версия процедуры
- WHEN процедура изменена
- THEN запуски продолжают использовать закреплённую версию
- AND это видно в записи задачи

### Requirement: Разовая корректировка не меняет процедуру
Доработка результата по просьбе владельца НЕ ДОЛЖНА изменять процедуру. Изменение
процедуры — только явная команда.

#### Scenario: Сократить текущий отчёт
- GIVEN владелец просит сократить текущий отчёт
- WHEN агент выполняет просьбу
- THEN создаётся ревизия результата
- AND процедура остаётся прежней версии

#### Scenario: Явная правка
- GIVEN владелец явно просит изменить будущие отчёты
- WHEN он вызывает правку процедуры
- THEN создаётся новая версия
- AND следующие запуски используют её после активации
