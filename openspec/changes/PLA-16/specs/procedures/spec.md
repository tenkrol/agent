# Дельта для домена procedures

## ADDED Requirements

### Requirement: Сохранение процедуры по явному запросу
Система ДОЛЖНА сохранять процедуру только по явному запросу владельца: назначение, входные
параметры, формат результата, критерии проверки и ограничения. Процедура не появляется
автоматически из повторяющегося запроса.

#### Scenario: Сохранение из задачи
- GIVEN владелец выполнил задачу и просит сохранить её как процедуру
- WHEN сохранение подтверждено
- THEN создаётся версия 1 с формулировкой, критериями и ограничениями из задачи
- AND процедура появляется в списке

#### Scenario: Без явного запроса
- GIVEN владелец повторяет похожие поручения
- WHEN он не просил сохранять процедуру
- THEN процедура не создаётся
- AND поведение задачи не меняется

### Requirement: Версии процедуры неизменяемы
Изменение процедуры ДОЛЖНО создавать новую версию. Ранее сохранённые версии НЕ ДОЛЖНЫ
перезаписываться, а задача ДОЛЖНА хранить использованную версию.

#### Scenario: Явная правка
- GIVEN процедура существует
- WHEN владелец явно меняет назначение или формат
- THEN создаётся версия 2
- AND версия 1 остаётся доступной

#### Scenario: Разовая корректировка
- GIVEN владелец просит сократить текущий отчёт
- WHEN агент выполняет просьбу
- THEN изменение относится к текущему результату
- AND процедура не меняется

### Requirement: Запуск создаёт отдельную задачу с версией
Ручной запуск и запуск по расписанию ДОЛЖНЫ создавать отдельную задачу, фиксировать версию
процедуры и использовать её критерии результата.

#### Scenario: Еженедельный обзор
- GIVEN сохранена процедура подготовки обзора
- WHEN владелец запускает её вручную или по расписанию
- THEN создаётся отдельная задача
- AND фиксируется версия процедуры
- AND используются её критерии результата

#### Scenario: Правка между запусками
- GIVEN процедура изменена между двумя запусками
- WHEN наступает следующий запуск
- THEN новая задача использует активную версию
- AND уже созданные задачи сохраняют прежнюю версию

### Requirement: Ограничения процедуры не выше глобальных
Процедура НЕ ДОЛЖНА превышать глобальные лимиты задачи и не даёт новых прав, команд или
доступа.

#### Scenario: Слишком большой бюджет
- GIVEN процедура просит бюджет больше глобального
- WHEN процедура сохраняется или запускается
- THEN система отклоняет превышение
- AND объясняет допустимый предел

### Requirement: Процедура описывает формат и проверку
Процедура ДОЛЖНА содержать формат результата и критерии проверки; при запуске они попадают
в задачу и в проверку результата.

#### Scenario: Проверка по критериям процедуры
- GIVEN процедура требует разделы отчёта
- WHEN результат проверяется
- THEN критерии процедуры обязательны
- AND отчёт показывает, какие из них пройдены
