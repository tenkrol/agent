# Дельта для домена execution

## ADDED Requirements

### Requirement: Формат и критерии процедуры в промпте
Промпт задачи, созданной из процедуры, ДОЛЖЕН содержать формат результата, критерии
проверки и значения параметров, чтобы исполнитель работал по процедуре, а не по памяти.

#### Scenario: Задача по процедуре
- GIVEN задача создана из версии процедуры
- WHEN собирается промпт
- THEN в нём есть формат результата и критерии
- AND параметры подставлены в текст

### Requirement: Ограничения процедуры не отменяют глобальные
Ограничения процедуры ДОЛЖНЫ применяться в пределах глобальных лимитов задачи; процедура
НЕ ДОЛЖНА повышать лимиты токенов, шагов, времени или менять права исполнителя.

#### Scenario: Лимиты процедуры
- GIVEN процедура задаёт свои лимиты
- WHEN задача запускается
- THEN действует минимум из лимитов процедуры и глобальных
- AND повышение сверх глобального отклоняется
