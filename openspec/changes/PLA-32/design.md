# Решение

- Контрольная строка добавляется в README отдельным абзацем в разделе «Тесты и
  разработка»: так она рядом с командой прогона тестов и не меняет описание продукта.
- Тест `test/readme.test.mjs` читает README из корня репозитория и требует строку
  `E5 implementation check` в начале строки. Это защищает от случайного удаления отметки.
- Изменение только документационное: поведение агента, API и конфигурация не меняются,
  поэтому деплой не требуется.
