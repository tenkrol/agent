# PLA-27 / E3: процесс GitHub и репозиторий заявок

Основание: `222.md`, E3. Проверено: репозиториев `tenkrol/specs`,
`tenkrol/assistant-work`, `tenkrol/requests` пока нет.

## Зачем
Нужен однозначный процесс: заявка и SHA спеки → компонентные изменения → ветка →
PR → проверки → merge → release. Сейчас агент коммитит напрямую в main, заявок нет.

## Что меняется
- Формат заявки: `requests/REQ-XXXX/manifest.json` + request/proposal/acceptance.
- Валидатор манифеста: компоненты, changeId, commit SHA, политика, отсутствие секретов.
- Правило workflow: ветка задачи → проверки → PR → merge → выпуск; прямой push в main
  для доработок запрещён.
- Решение о имени/видимости репозитория и GitHub-доступе — за владельцем.

## Не входит
Создание репозитория до подтверждения имени; GitHub-приложение/токен; E4+.
