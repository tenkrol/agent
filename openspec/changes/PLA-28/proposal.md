# PLA-28: версия установленного релиза в health

Основание: REQ-0002, E3 — первый сквозной поток заявки через два компонента.

## Что меняется
- `GET /v1/health` отдаёт `release` (имя установленного релиза), не раскрывая путей/секретов.
- Бот сможет показать владельцу установленную версию агента.

## Проверка
- bridge-тест: health с release; без release поле отсутствует.
