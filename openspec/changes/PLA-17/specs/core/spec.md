# Дельта для домена core

## ADDED Requirements

### Requirement: Управление памятью командами
Ядро ДОЛЖНО позволять владельцу просматривать действующую память, её историю, явно
исправлять устаревший факт, задавать срок актуальности и забывать факт.

#### Scenario: Просмотр
- GIVEN в памяти есть действующие и заменённые факты
- WHEN владелец вызывает `/memory`
- THEN видны действующие факты по видам и областям с датами и источником
- AND история доступна отдельной командой

#### Scenario: Явное исправление
- GIVEN сохранён устаревший факт
- WHEN владелец явно сообщает новый с тем же предметом
- THEN новый становится действующим
- AND прежний не используется и виден в истории

### Requirement: Проверка отчёта на секреты
Перед отправкой отчёта ядро ДОЛЖНО проверить текст на значения известных секретов и
вырезать их, сообщив владельцу, что фрагмент был вырезан.

#### Scenario: Секрет в результате
- GIVEN собранный отчёт содержит значение секрета
- WHEN отчёт готов к отправке
- THEN значение вырезается
- AND владелец получает предупреждение без значения
- AND секрет не попадает в лог

### Requirement: Разделение владельцев памяти
Личные факты, переданные ассистентом, ДОЛЖНЫ использоваться только в текущей задаче и НЕ
ДОЛЖНЫ сохраняться агентом. Рабочие факты агент хранит сам, а для долговременного хранения
личных — предлагает их ассистенту.

#### Scenario: Личный факт в задаче
- GIVEN ассистент передал личные факты для задачи
- WHEN задача завершена
- THEN факты не остались в памяти агента
- AND другие задачи их не видят

#### Scenario: Рабочий факт
- GIVEN агент вывел устойчивый рабочий факт
- WHEN он хочет сохранить его
- THEN уходит предложение ассистенту
- AND молчаливая запись личного факта не выполняется
