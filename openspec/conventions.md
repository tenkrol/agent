# Конвенции проекта агента

- Спеки, документация и комментарии — по-русски.
- Код меняется только в рамках `openspec/changes/<дата>-<имя>/`.
- Тесты: `node --test --test-force-exit`, даты вычисляемые.
- Деплой — через установщик `deploy/setup-outbox.sh` и перезапуск `dsh-agent`.
- Секреты открытым текстом не храним: `secrets/agent.env.enc` + пароль вне репозитория.
- DoD: спека соответствует коду, тесты зелёные, установщик обновлён, изменение заархивировано.
