# Конвенции проекта агента

## Язык
Спеки, документация и **комментарии в коде — по-русски**. Английские комментарии
переводим по мере правки файлов, не отдельной задачей.

## Изменения только через change
Код меняется только в рамках папки `openspec/changes/PLA-<номер>/` (номер сквозной по
порядку). Исключение —
опечатка или правка без изменения поведения: коммит с пометкой «без change».

## Правила кода
ES-модули, стрелки, без точек с запятой, отступ 2 пробела. Имена файлов — по назначению.
Ноль npm-зависимостей в рантайме. Домен не импортирует `bot.mjs` и не тянет чужие домены
напрямую — только через свои порты (см. спеку архитектуры).

## Тесты
`node --test --test-force-exit test/*.test.mjs`. Фикстуры — в `fixtures/`, даты только
вычисляемые от `Date.now()`. Доменные тесты работают без сети и без фейковой платформы.
**Перед деплоем — полный локальный прогон.**

## Деплой
Только `bash deploy/install-remote.sh` (идемпотентный: новый релиз + переключение
симлинка; откат — переключить `/opt/agent` на предыдущий релиз). Связь с ботом
настраивается отдельно: `deploy/setup-outbox.sh`, туннель — `deploy/setup-bridge-tunnel.sh`.
Установщик **никогда** не перезаписывает `/etc/agent/agent.env`, только дополняет
отсутствующие ключи.

## Коммиты
Одна задача — один осмысленный коммит, по-русски, с причиной. Ветка одна — `main`.

## Определение готовности (DoD)
1. дельта-спека соответствует коду;
2. тесты добавлены и зелены локально;
3. задеплоено через `deploy/install-remote.sh` и проверено на сервере;
4. `HANDOFF.md` обновлён;
5. изменение заархивировано (`changes/archive/PLA-<номер>/`), спеки влиты.

## Секреты
Открытым текстом — нигде: ни в репозитории, ни в чате, ни в логах. В репозитории только
шифртекст `secrets/agent.env.enc` и таблица имён `secrets/keys.md`; пароль — вне
репозитория; расшифровка `bash tools/secrets.sh decrypt`. На сервере источник истины —
`/etc/agent/agent.env` (640, root:agent). Ротация — `deploy/rotate-from-mac.sh`. Задача
не должна получать значения секретов в промпте.

## Запреты
- Не включать `MemoryDenyWriteExecute` (V8 падает) и не менять `ProtectControlGroups=false`.
- Не перезаписывать `/etc/agent/agent.env` установщиком.
- Не писать руками в `state/observations.jsonl`, `state/alerts.jsonl`, `state/alerts.json`,
  `state/tasks.jsonl` — их пишет сам агент.
- Не деплоить без полного локального прогона тестов.
- Не перезагружать серверы без разрешения владельца и не трогать xray/VPN на Испании.
