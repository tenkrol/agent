# Проект «Агент TenKrol»

Исполнитель длинных задач для чат-бота: принимает задачи по HTTP-мосту, выполняет их
через DSH в песочнице `workspace-write`, отвечает владельцу в свой Telegram-бот и
дублирует ответ в точку приёма чат-бота.

## Стек и ограничения
Node.js 22, systemd, ноль npm-зависимостей в рантайме. Песочница не даёт запускать внешние
команды и читать `/etc` — поэтому секреты приходят через окружение сервиса, а отчёты
собирает сторож по журналу (`agent-run-watch`).

## Домены
`agent-core` (приём и очередь задач), `agent-runner` (запуск DSH, парсинг результата),
`agent-link` (мост, точка приёма, туннель, сторож), `secrets`, `ops`.

## Секреты
`secrets/agent.env.enc`, пароль вне репозитория. Расшифровка: `bash tools/secrets.sh decrypt`.
